🟢 ABOUT PAGE

Professional Narrative (Refined Summary)

My university experience focused heavily on syllabus completion rather than practical, industry-ready knowledge. While fundamentals were repeatedly taught, real-world application was limited. I gained strong entry-level expertise in database design and development, but the lack of applied learning led me to leave university.

In 2020, I began my professional journey as a freelance developer, delivering my first production website using HTML, CSS, and JavaScript via Upwork. This marked the start of continuous self-driven learning and real-world problem solving.

Inspired by the rise of AI, I built object recognition applications using Python and OpenCV, then expanded into React, Node.js, MERN-based projects, and later Laravel-based enterprise systems.

Over time, I specialized in building ERP platforms, geolocation systems, HR tracking tools, and SaaS applications — delivering measurable business value across multiple industries.
